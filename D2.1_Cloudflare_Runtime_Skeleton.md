> **SUPERSEDED / 历史 checkpoint**  
> D2.1–D5、E3、W3D3 与 MG0 已完成。本文件仅记录最早的 Cloudflare runtime skeleton，不再描述当前能力或下一步。当前执行路线见 `开发计划_V5_客户端运行时与网络韧性实施路线.md`，长期架构见 `长期架构与DurableObjects迁移设计_V4.md`。

## Scope

This PR establishes only the first Cloudflare runtime shell:

- Worker health endpoint;
- stable `roomCode -> Durable Object name` routing;
- one minimal `GameRoomDurableObject` class;
- declarative Durable Object export using SQLite storage;
- contract tests that do not replace the current Node production runtime.

Explicitly deferred:

- RoomSnapshot persistence (D3);
- Durable Object alarms / interaction deadlines (D3/D4 as appropriate);
- Hibernation WebSocket (D4);
- Node / Cloudflare parity tests (D5);
- client migration.

## Local smoke test

This PR intentionally does not add Wrangler to the project dependency graph yet. To smoke-test the skeleton locally without changing `package-lock.json`:

```bash
npx wrangler@latest dev
```

Then verify:

```text
GET /health
GET /rooms/1234/identity
GET /rooms/1234/identity   -> same objectId
GET /rooms/5678/identity   -> different objectId
```

If D3 requires repeatable Wrangler tooling in CI, add Wrangler/generated Cloudflare types there as an explicit dependency change rather than coupling that dependency migration to this skeleton PR.
