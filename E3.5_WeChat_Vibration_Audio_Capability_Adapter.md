# E3.5 WeChat vibration / audio capability adapter

## Goal

Connect the existing transport-neutral `client:event` effect protocol to native WeChat capabilities without moving game rules, authority, or effect durability into the client.

```text
ClientSession.subscribeRealtimeEvents
        ↓
ClientEffectDispatcher
        ↓
WeChatClientEffects
        ├─ vibrateShort / vibrateLong
        └─ semantic audio cue -> platform asset
```

## Vibration mapping

The stable protocol keeps a browser/native-neutral vibration pattern such as:

```text
[300, 150, 300]
```

WeChat does not expose the Web Vibration API's arbitrary pattern primitive. The adapter therefore preserves relative timing and approximates each vibration segment using the platform's short/long vibration primitives. The default long threshold is 200 ms and remains adapter configuration rather than protocol semantics.

## Semantic audio

The protocol sends a semantic cue such as:

```text
night-complete
```

It does not send a browser URL or an audio implementation instruction. The WeChat adapter maps that cue to an asset path supplied by the native client and lazily creates/reuses an `InnerAudioContext`-like object.

## Failure policy

These effects remain transient and best-effort:

- unsupported vibration/audio capability is a safe no-op;
- malformed effects remain ignored by the shared dispatcher;
- immediate platform failures are contained by `ClientEffectDispatcher`;
- delayed vibration callback failures are caught inside the WeChat adapter;
- detach cancels pending vibration timers and releases audio contexts;
- reconnect does not replay missed effect history;
- duplicate/reordered effects remain acceptable;
- no effect changes authoritative PlayerView or connection state.

## Explicit non-goals

E3.5 does not add:

- durable effect outbox or inbox;
- effect ACK/retry;
- background guaranteed delivery;
- WeChat UI pages;
- game-rule-specific vibration decisions;
- hard-coded production audio assets.

Durable eventual-delivery effects remain R1 scope.
